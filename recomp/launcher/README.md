# Launcher box art

`boxart.tga` is a 512x512 launcher copy of the North American
Mario Kart: Super Circuit cover.

Source:
https://www.mariowiki.com/File:MKSC_Box_Art.png

The source page identifies Nintendo's Game Boy Advance - Nintendo Switch
Online store page as the original source. The copyrighted cover is included at
launcher resolution solely to identify the game.
